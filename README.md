### `01 / Artificial Intelligence`

Exploring the engineering behind intelligent systems — from data preparation and model integration to deployment, evaluation, and production reliability.

- Machine learning fundamentals and model evaluation
- LLM applications, APIs, and prompt engineering
- Retrieval-augmented generation (RAG) and vector search
- AI agents, tool use, and workflow orchestration
- Data pipelines, inference, and model serving
- AI application observability, evaluation, and cost optimization

### `02 / Systems Engineering`

Understanding the operating environments that software depends on.

- Linux administration and command-line workflows
- Processes, threads, permissions, and resource management
- Filesystems, storage, services, and system logs
- Shell scripting and operational automation
- Virtualization, containers, and environment management
- Troubleshooting, performance analysis, and reliability

### `03 / Networking & Infrastructure`

Learning to reason about connectivity, traffic, addressing, and communication across systems.

- TCP/IP, OSI model, and packet analysis
- IPv4, IPv6, subnetting, and CIDR
- DNS, DHCP, NAT, routing, and switching
- HTTP/HTTPS, TLS, ports, and network services
- Firewalls, access control, VPNs, and network segmentation
- Connectivity troubleshooting and network observability

### `04 / DevOps & Automation`

Connecting development with repeatable, reliable operations.

- Git, GitHub, and version-controlled workflows
- Docker, containerization, and reproducible environments
- CI/CD fundamentals and deployment pipelines
- Python and shell scripting for automation
- Infrastructure as Code concepts
- Monitoring, logging, configuration, and incident analysis

### `05 / Security & Reliability`

Building with the assumption that systems must be protected, observable, and resilient.

- Least privilege and identity-based access
- Secrets management and environment configuration
- Secure API design and authentication fundamentals
- Dependency hygiene and vulnerability awareness
- Backup, recovery, and failure analysis
- Defense in depth and security-first engineering

## `engineering_principles`

| Principle | What it means in practice |
|:---|:---|
| **Understand the fundamentals** | Learn what happens underneath the abstraction. |
| **Automate intelligently** | Eliminate repetitive work without hiding important failure modes. |
| **Design for reliability** | Expect failures, observe behavior, and make recovery possible. |
| **Secure by default** | Minimize privileges, protect secrets, and validate inputs. |
| **Measure before optimizing** | Use evidence rather than assumptions to guide improvements. |
| **Keep learning** | Treat documentation, experimentation, and debugging as daily tools. |
| **Build with intent** | Prefer useful, maintainable solutions over unnecessary complexity. |

## `what_i_want_to_build`

My ideal engineering work sits at the intersection of intelligence, infrastructure, and automation.

- **Intelligent systems** — AI applications that solve practical problems and can be evaluated reliably.
- **Infrastructure-aware AI** — applications that account for compute, memory, latency, networking, and deployment constraints.
- **Automation tools** — scripts and services that remove operational friction.
- **Self-hosted services** — maintainable deployments with sensible security and monitoring.
- **Network-aware applications** — systems designed with connectivity, protocols, and failure scenarios in mind.
- **Developer tooling** — utilities that make workflows simpler, faster, and more reproducible.

The objective is not to collect technologies. It is to understand how they fit together and use them to build systems that work.
